# Background music

`snowfall.mp3`, `hearth.mp3` and `lanterns.mp3` are original ambient piano pieces written for
DJ December by `scripts/music/compose.py` and rendered with FluidSynth using the
FluidR3_GM soundfont (MIT license, © Frank Wen). They contain no third-party recordings,
so they can be hosted and played freely; no attribution is required.

To regenerate (Ubuntu): `apt-get install fluidsynth fluid-soundfont-gm`, `pip install mido`, then
see the comments in `scripts/music/compose.py`.
